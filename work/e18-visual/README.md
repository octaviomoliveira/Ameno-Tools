# E18 visual gallery

Generated offscreen with `tools/render-e18-gallery.py` on 2026-09-09. The five
PNGs cover the authenticated Cotar, Aparência, Revisar, Exportar and
Configuração pages at 1120×760. They are visual evidence for the E18 review
checkpoint; the final acceptance still requires opening the canary in the
3ds Max 2026 host and checking the real viewport/DPI environment.

The first-use onboarding flow is covered by `tests/python/test_e18_create_first_use.py`
and the compact host layout by `tests/maxscript/test_e18_qt_host.ms` and
`tests/maxscript/test_e18_installed_host.ms`.
