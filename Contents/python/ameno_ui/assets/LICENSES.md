# Ameno UI assets

## Ameno wordmark and symbol

The PNG files in `brand/` are runtime variants derived from the Ameno V2
masters owned by Ameno. The source files are not modified by the build.

- source wordmark: `ameno-v2-standard-transparent.png`
- source symbol: `ameno-v2-symbol-o-transparent.png`
- derived colors: off-white `#E8E8E0` and Ameno red `#E63B2E`
